# CareFlow dashboard website

Responsive static dashboard inspired by the provided reference image. It uses synthetic demo metrics only and has no backend, user authentication, role-based access enforcement, audit logging, or hospital/EHR integration.

## Publish using GitHub Pages
1. Create/sign in to GitHub and create a public repository (for example `careflow-dashboard`).
2. Upload `index.html`, `robots.txt`, and `sitemap.xml` to the repository root.
3. In repository Settings → Pages, choose deploy from branch `main`, folder `/ (root)`, and save.
4. Wait for GitHub Pages to provide your public URL.
5. Replace `YOUR-DOMAIN.example` in `robots.txt` and `sitemap.xml` with the real published domain, then commit the changes.
6. Open Google Search Console, add/verify the domain or URL-prefix property, submit `/sitemap.xml`, and request indexing for the home page.

Google indexing is not immediate or guaranteed. Use a real domain and contact details before presenting this as a public business website.

## Important safety note
This is a design/demo only. Do not enter real patient information. Before actual hospital deployment, commission security and privacy review, authentication, per-role authorization, secure hosting, encryption, audit trails, backup/recovery, and approved integration with hospital systems. Follow applicable laws and hospital policy.
